01 / The idea

Keep the state full.
Make the reads small.

A recurrent state carries information into every future step. Compressing that state can carry approximation errors forward, too. SketchSSM preserves full-state updates and approximates only the readout to avoid propagating state-compression errors into subsequent decoding steps.*

State-write access: Already amortized across multiple decoding steps by ReplaySSM, making full-state updates affordable while avoiding state-compression error propagation.

State-read access: Reduced by reading from a compact sketch refreshed alongside each full-state update.

02 / How to Make a Sketch

Preserve the output.
Build a compact query basis.

Within each window, the full state stays fixed, but the effective query changes at every decoding step. Computing each query's output directly therefore requires rereading the same full state.

Our idea is to approximate these changing queries with a small, fixed query basis. A single full-state read at the flush step precomputes the outputs for all basis vectors, forming a compact sketch. Subsequent queries combine these precomputed outputs instead of rereading the full state.

To choose a basis that preserves the output, we minimize output reconstruction error—equivalently, state-weighted query approximation error.

ℰt=∥S0⊤q~t−Uct∥22=∥H12(q~t−Ωct)∥22

H = S0S0⊤; S0 is the full state at the window boundary, and q̃t is the effective query incorporating within-window transitions.

Offline · Fixed

Sketching matrix

ℒG(Ω)=𝔼𝒟[minc∥E012(q~t−Ωc)∥22]
Ω⋆=E0−12PG

Use the average state geometry E0 = 𝔼𝒟[S0S0⊤]. Uncentered PCA of zt = E01/2q̃t gives PG, the top G eigenvectors of 𝔼𝒟[ztzt⊤]. Calibrate once per state head; keep the basis fixed during inference.

Per window · Flush

Sketch & coefficient map

U=S0⊤Ω⋆
C=(U⊤U)†U⊤S0⊤

Refresh U and the state-dependent map C with each full-state update. Sketch construction is fused into the update kernel. Here, † denotes the pseudoinverse; the implementation uses an efficient approximation of C.

Per step · Non-flush

Coefficient vector & readout

ct=Cq~t,o^tstate=Uct

Choose query-dependent coefficients that minimize ∥S0⊤q̃t − Uc∥22, then combine the sketch vectors. Read only the compact sketch and map; the buffered contribution to the output remains exact.

03 / Accuracy

About 10× less state traffic.
Accuracy largely preserved.

Across four models spanning Mamba-2, Gated DeltaNet, and KDA, SketchSSM largely preserves average accuracy across four benchmarks while reducing state-access traffic by approximately 10×.

Follow the green curves. Moving right means less state traffic; staying high means better accuracy. Pruning and quantization lose accuracy at smaller traffic reductions because errors introduced by state compression propagate across decoding steps.

Sketch rank controls the accuracy–traffic trade-off. Larger traffic reductions can decrease accuracy.
